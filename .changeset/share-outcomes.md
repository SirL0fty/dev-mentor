`share` now asks whether you're sharing a plan (for review before building), a lesson (a note for Notion or Obsidian) or an outcome. It can report the outcome of a debate, challenge or review as an ADR that keeps every reviewer's position, disagreement and open question, and can share it as a Plannotator link (the default, installed only if you choose), an HTML file with an optional password, or in a tool you already use. `devils-advocate` now keeps a debate record for it.
