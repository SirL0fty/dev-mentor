What you see now matches your level, in every example: a code change, a command, a test result, an error or a request traced through the code. Everyone sees the real evidence. New to code and vibe coder get it trimmed and explained (what it means, how it runs, what to look for) with one real example traced step by step; junior and up get the full command and output to confirm it themselves. "Passed" never appears without its evidence. When something can be run, it asks whether you or the AI runs it, at every level. `show output`, `show the flow` and `how do I run that?` work any time.
