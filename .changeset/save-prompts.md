Dev Mentor now offers to save moments worth keeping, such as a concept that clicked, a fix and what to check next time, or a decision and its reasons, as one entry in a learning log in Obsidian, Notion or a Markdown folder. Say `save note` to save it, or `save prompts off` to stop the offers. When your assistant can run a script that calls other tools (such as OpenCode's Code Mode), bulk reads are batched so only the results reach the chat.
