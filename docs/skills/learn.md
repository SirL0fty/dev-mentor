# learn

[Skill file](../../skills/learn/SKILL.md)

## What it does

`learn` teaches a concept or technology with a concrete problem first, one realistic example, one way it breaks, and an optional exercise. It works with or without a codebase.

## When to reach for it

Ask "teach me X", "help me understand X properly" or "quiz me on X", or use it for exam and certification study. For how this project's own code works, use `explain`.

## It's working if

- It opens with the problem the concept solves, before the definition.
- Version-specific facts name the version and come from current official docs.
- Examples from your repo are real; otherwise they're labelled illustrative.
- Quizzes are optional and never block you; a passing exercise isn't called mastery.
